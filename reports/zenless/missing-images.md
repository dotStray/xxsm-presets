# zenless: characters with no portrait

10 characters have no picture. The app shows their initials instead. To add one, put a picture in `manual/zenless/images/` named after the character, like `AriaRobot.png`.

- **AriaRobot** — Aria Robot: no picture in any source
- **AriaRobotDiscordant** — Aria Robot Discordant: no picture in any source
- **Belle** — Belle: no picture in any source
- **BelleBrilliance** — Belle Brilliance: no picture in any source
- **BelleSummer** — Belle Summer: no picture in any source
- **BelleSunlight** — Belle Sunlight: no picture in any source
- **Wise** — Wise: no picture in any source
- **WiseCrane** — Wise Crane: no picture in any source
- **WiseSkies** — Wise Skies: no picture in any source
- **WiseSummer** — Wise Summer: no picture in any source
